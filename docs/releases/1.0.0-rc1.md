# Kindle Cards 1.0 для Windows x64

Это закрытый кандидат для проверки с читалкой. Установщик Windows x64 — `Kindle Cards_1.0.0_x64-setup.exe`, SHA-256 — `1e92adc7553f7f178d424d8d998f6ce48dc4dd42a123f29f80067f8609bf1f06`. После установки откройте Kindle Cards из меню «Пуск». Заголовок окна — **Kindle Cards 1.0**.

## Проверка с Kindle

1. Подключите Kindle кабелем с передачей данных. На Главной нажмите **«Найти Kindle»**. Когда появится название читалки, нажмите **«Загрузить слова с читалки»**. Если устройство недоступно, можно выбрать копию `system/vocabulary/vocab.db` через **«Выбрать файл»**.
2. После обработки откройте **«Слова»**. Найдите знакомое слово и откройте его карточку. Проверьте причину приоритета, перевод и предложение из вашей книги. Для слова с измеренным книжным охватом оценка доступна уже после одного поиска.
3. Вернитесь на Главную. По умолчанию выбрана **«Вся библиотека»**. Перед нажатием посмотрите на число и назначение на кнопке. Первые пять слов — предпросмотр. Для небольшой пробы выберите **«Порция новых слов»** и введите нужное число. Если вы хотите проверить только состав файла, в Настройках выберите **«Подробный TSV»**.
4. Отключите и подключите Kindle, снова загрузите тот же словарь. Количество слов и книжных цитат должно остаться прежним. После нового поиска на читалке в библиотеке должно появиться соответствующее слово или ещё одно обращение к уже известному слову.

Anki принимает колоду через AnkiConnect или файл `.apkg`. Для обновления полей важны настройки импорта в Anki. Obsidian создаёт Markdown-карточки в отдельной папке выбранного хранилища. Quizlet и RemNote получают файлы для ручного импорта. ИИ для этих операций не требуется.

## Обновление с 0.4.0

Кандидат использует обычный профиль Kindle Cards. При первом открытии старой библиотеки приложение создаёт и проверяет резервную копию SQLite перед переходом со схемы 4 на 5. База и автоматические копии находятся в `%APPDATA%\com.kindlevocab.cards\.app-data`; настройки хранятся отдельно в том же каталоге.

Для полного возврата закройте Kindle Cards, сохраните текущий профиль отдельно и восстановите профиль, снятый **до** обновления, перед запуском 0.4.0. Изменения, сделанные уже в 1.0, останутся в сохранённой новой копии. Переустановка старого приложения сама по себе не возвращает прежние данные. Внешние колоды и хранилища имеют собственную историю.

Происхождение таблицы книжного охвата и условия использования приведены в [описании модели](../../packaging/ranking-model-notices.txt). Публичный установщик предыдущей версии указан в [заметках к 0.4.0](0.4.0.md).
